# Building

This project is a Windows-only C++ application. It uses native Win32 APIs and does not depend on any third-party runtime libraries.

## Fresh Clone Checklist

After cloning the repository, you should have everything needed to build the project from source:

- source files
- resource files
- icons and artwork
- documentation
- the MIT license

The build products are generated locally and should not be committed.

## Build Inputs

The checked-in files required to build are:

- `MonitorInputSwitcher.cpp`
- `mis_monitor.h`
- `mis_config.h`
- `mis_cli.h`
- `mis_icons.h`
- `app.rc`
- `app.ico`
- `tray-light.ico`
- `tray-dark.ico`
- `build.bat`

## Toolchains

`build.bat` supports either of these toolchains:

- Microsoft Visual C++ with the Windows SDK resource compiler
- MinGW-w64 with `g++` and `windres`

The script auto-detects the available toolchain and prepends the correct MSYS2 MinGW bin directory when needed.

## Build Steps

From a Windows command prompt in the repository root, run:

```bat
build.bat
```

The script produces:

- `MonitorInputSwitcher.exe` for the GUI
- `mis-cli.exe` for the console twin
- temporary object and resource files that can be deleted after the build finishes

## Manual Build Notes

The project is compiled twice from the same translation unit:

- once as a Windows subsystem executable for the GUI
- once with `MIS_CLI` defined as a console subsystem executable

The resource file embeds the application icon and tray icons in the executable.

## Optional Asset Regeneration

The icon set is generated by `make_icons.py` and `make_app_icons.py`.

That script requires:

- Python 3
- `numpy`
- `Pillow`

The generated PNG and ICO assets are already checked into the repository, so running the Python scripts is optional unless you want to regenerate the artwork.
